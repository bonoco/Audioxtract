# AudioXtract

App Android para extrair o áudio de arquivos de vídeo de forma rápida e simples.

## Recursos

- Extrai o áudio de vídeos direto no celular
- Interface moderna e arredondada (Material 3)
- Funciona offline
- Leve: instala só o essencial

## Em breve

- Extração de legenda a partir da fala (Whisper offline), como recurso opcional. O modelo só é baixado se você quiser, para o app continuar leve.

## Como instalar

1. Vá na aba [Releases](../../releases) deste repositório.
2. Baixe o arquivo `.apk` da versão mais recente.
3. Abra o arquivo no celular e permita a instalação de fontes desconhecidas, se o Android pedir.

## Como compilar

1. Clone o repositório:
   ```
   git clone https://github.com/SEU_USUARIO/AudioXtract.git
   ```
2. Abra a pasta no **Android Studio**.
3. Aguarde o Gradle sincronizar.
4. Conecte um celular (ou use o emulador) e clique em **Run**.

## Tecnologias

- Kotlin
- Android Studio
- Material Design 3
